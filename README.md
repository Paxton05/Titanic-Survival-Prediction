# Titanic Survival Prediction

A machine learning classification project that predicts passenger survival using the Titanic dataset.

## Project Overview

This project applies data cleaning, missing-value handling, feature encoding, feature scaling, and multiple classification algorithms to predict whether a passenger survived.

## Dataset

The Titanic dataset contains passenger information such as:

- Passenger Class
- Sex
- Age
- SibSp
- Parch
- Fare
- Embarked
- Survival

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Workflow

The project includes:

1. Data loading and understanding
2. Data cleaning
3. Missing-value handling
4. Feature selection
5. Categorical feature encoding
6. Feature scaling using StandardScaler
7. Train-test splitting
8. Model training
9. Model evaluation

## Machine Learning Algorithms

The following classification algorithms were implemented:

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Naive Bayes
- Decision Tree
- Support Vector Machine (SVM)

## Model Evaluation

The models were evaluated using:

- Accuracy Score
- Confusion Matrix
- Classification Report
- Cross-Validation
